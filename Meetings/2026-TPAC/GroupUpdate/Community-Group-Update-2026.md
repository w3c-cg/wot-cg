## Introduction

This past year, the Web of Things at W3C took meaningful steps forward thanks to a diverse community of contributors across multiple groups. We'd like to share a few of the highlights with you.

> Visualise the different groups with the opening animation and then go into each of them one by one

## Working Group Section

Thanks to the working group, new features have arrived in the Web of Things standard. The Thing Description gained Common Definitions, which let you declare shared details once instead of repeating them across a description.

There is now also a binding registry, which opens the door for standardization work outside of W3C to contribute - OPC UA is one example of such a collaboration. Alongside it, new protocol bindings are available and already in use in real-world systems.

A new charter is in place as well, starting September 2026 and setting the direction for the year ahead - so if you're interested in standardization for the Internet of Things, this is a good moment to get involved.

## Web Thing Protocol Community Group Section

This year, the Web Thing Protocol Community Group released the first specification of the Web Thing Protocol. It is the protocol built natively on the Thing Description model to work on top of WebSockets. Implementations are already running, and it's heading toward the Working Group for standardization.

## General Section + Call to Action

The Web of Things is open source at heart, and it grows with every new contributor. If you're interested in getting involved, a great place to start is our newly reworked website, which brings together all relevant information in one place. From there you can also reach each group individually and you can click the links in the description to join us, or connect with us on GitHub and Discord.
